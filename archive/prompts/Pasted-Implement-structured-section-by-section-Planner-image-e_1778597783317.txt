The issue is NOT token truncation.

The debug report showed:

* token limit was not hit
* no JSON parse error
* no OCR fallback
* no validation stripping
* client did not hide the missing items

The AI simply failed to extract all visible content from the image.

It focused on the obvious planned-meal table and ignored:

* lunch ideas
* shopping-list items
* handwritten notes
* other visible sections

Rewrite the planner vision extraction prompt to force structured, exhaustive section-by-section extraction.

The AI must inspect the image in phases:

1. Planned meals
2. Lunch ideas / flexible meal ideas
3. Shopping-list items
4. Handwritten notes / contextual modifiers
5. Uncategorised visible text

EXTRACTION RULES

1. Exhaustive scan rule
   The AI must not stop after finding the main table.

It must inspect:

* top margin
* bottom margin
* left side notes
* right side notes
* handwritten overlays
* printed table
* handwritten additions near table rows

2. Section-first rule
   Before extracting items, identify visible sections such as:

* Lunches
* lunch ideas
* meal ideas
* batch cook
* shopping list
* ingredients
* notes
* table rows

3. Planned meals
   Extract scheduled/table meals into meals[] with proposedType="scheduled" where appropriate.

4. Lunch ideas
   Extract top/side standalone lunch/flexible meal lists into meals[] with proposedType="meal_idea".

Example:
"Lunches"

* ham bread
* pizza toast
* veg & hummus
* fish fingers salad / sandwiches

These must not disappear.

5. Shopping items
   Extract ingredient/shopping-list style items into shoppingItems[].

Examples:

* passata x4
* yogurt
* basil
* carrots
* eggs x40

These must not be placed in planned meals.

6. Handwritten modifiers
   If a handwritten note modifies a printed row, combine it into interpretedName but preserve sourceText.

Example:
Printed row:
Fish cakes

Nearby handwriting:
new pots salad

Result:
label: "Fish cakes new pots salad"
interpretedName: "Fish cakes with new potatoes and salad"
contextNote: "Combined printed row with nearby handwritten note"

7. Do not over-merge unrelated rows
   Do NOT combine separate meals just because they are visually nearby.

Bad:
"Chicken noodle vegetable spaghetti salad"

Better:

* "Chicken noodle salad"
* "Vegetable spaghetti salad"

If uncertain, split rather than merge.

8. Raw text coverage
   rawText must include substantially all readable text, not just the table.

If the image clearly contains lots of handwritten shopping items, rawText should reflect that.

9. Unknown section
   If visible text cannot be confidently classified:

* include it in rawText
* optionally create unknown meal proposal only if it looks meal-like
* do not discard it silently

10. Warnings
    Add a warning if:

* handwriting is difficult
* parts are obscured
* section classification is uncertain

But avoid duplicate warnings.
