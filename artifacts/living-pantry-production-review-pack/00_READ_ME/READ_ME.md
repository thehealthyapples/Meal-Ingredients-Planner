# Living Pantry — Production Image Review Pack

Read-only visual audit pack. **No approvals, no edits, no generation.** Start with `REVIEW_GUIDE.md`.

Contents:
- `IMAGE_MANIFEST.md` / `image-manifest.json` — every image, its origin, dimensions, proposed role, evidence status, known issues.
- `01_ARRIVAL` … `10_WORKTOP` — per-Working-Position images (MASTER_A_CANDIDATES / MASTER_B_CANDIDATES / CURRENT_RUNTIME / PREVIOUS_OR_REJECTED / EXTRACTED_OBJECTS / EVIDENCE).
- `11_PERMANENT_PROPS` — index of permanent room props and where they appear.
- `12_LIVING_OBJECT_CANDIDATES` — Living Object candidate families.
- `13_RUNTIME_EVIDENCE` — screenshots / continuity comparisons of the running app.
- `14_CONTACT_SHEETS` — labelled thumbnail sheets (open the `.html` files in a browser).

No file in this pack is a canonical or approved asset. It is a review copy only.
