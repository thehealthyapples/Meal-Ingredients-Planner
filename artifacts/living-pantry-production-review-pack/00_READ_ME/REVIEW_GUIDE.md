# Living Pantry — Review Guide

You are reviewing the Living Pantry as **one physical room**. No repository access is needed; every image is inside this pack. Nothing here is approved — this pack makes no approval claims.

## Assess, in order
1. **Same physical room** — do all views read as one room?
2. **Camera Truth** — could each close view have been photographed from a spot in the Arrival room?
3. **Canonical fixture continuity** — does each fixture match the one seen in `01_ARRIVAL`?
4. **Master A validity** — is there a correct-fixture view with NO movable objects?
5. **Master B validity** — is there the *identical* view, populated?
6. **Pixel compatibility** — do A and B match in fixture/furniture/camera/crop/geometry/lighting/perspective/props (only objects differing)?
7. **Extractability** — can the Living Objects be cleanly cut from B?
8. **Permanent prop consistency** — are scales, kombucha vessel, baskets, rack, etc. the same object across views? (see `11_PERMANENT_PROPS`)
9. **Living Object quality** — are candidate objects photoreal and correctly lit? (see `12_LIVING_OBJECT_CANDIDATES`)
10. **Label treatment** — chalkboard labels part of artwork; runtime text only; no floating labels/plaques.
11. **Runtime evidence** — how do current objects actually render? (see `13_RUNTIME_EVIDENCE` and each `*/EVIDENCE`)
12. **Production readiness** — classify each Working Position:

## Classification key
- 🟢 **Ready for extraction** — canonical A + canonical B + pixel-compatible pair + extractable objects
- 🟡 **Missing Master B** — canonical empty A exists, populated identical B does not
- 🟠 **Missing Master A** — populated view exists, empty identical A does not
- 🔴 **Requires re-authoring** — no correct-fixture master (e.g. wrong appliance)
- ⚪ **Unverified** — fixture/canonical status not yet confirmed
