# CREATE_UI_AUDIT_PACKAGE

**Summary:** Create a complete UI Audit Package containing all screenshots, an HTML gallery, and the accompanying audit report so ChatGPT can perform a full launch-readiness UX review.

---

## Objective

Create a self-contained UI Audit Package.

This package should allow the entire application to be reviewed visually without needing to manually open individual screenshots.

No application functionality should be changed.

This is documentation only.

---

## Folder Structure

Create:

```text
docs/ui-audit/

README.md
index.html

reports/
WX9A_LAUNCH_EXPERIENCE_VISUAL_AUDIT.md

screenshots/

desktop/
laptop/
tablet/
mobile/
```

---

## Move Existing Report

Move (or copy if preferred):

```text
docs/ui-audit/WX9A_LAUNCH_EXPERIENCE_VISUAL_AUDIT.md
```

into

```text
docs/ui-audit/reports/
```

The final structure should keep all audit reports together.

Future audit reports should also be stored in this folder.

---

## HTML Gallery

Generate:

```text
docs/ui-audit/index.html
```

The gallery should automatically discover every screenshot beneath:

```text
docs/ui-audit/screenshots/
```

Display screenshots grouped by page.

Example:

---

# Dashboard

Desktop

[image]

Laptop

[image]

Tablet

[image]

Mobile

[image]

---

# Planner

Desktop

...

---

The page should be clean and easy to scroll.

Images should scale responsively.

Clicking an image should open the full-resolution version.

No external libraries required.

Pure HTML/CSS/JS.

---

## README

Create:

```text
docs/ui-audit/README.md
```

Include:

* audit purpose
* folder structure
* how to add new screenshots
* how to regenerate the gallery
* how to open the HTML locally

## Screenshot Naming

Use consistent names.

Example:

```text
01-dashboard-desktop.png
01-dashboard-laptop.png
01-dashboard-mobile.png

02-planner-desktop.png

03-cookbook-desktop.png

04-meal-detail-breakfast-burrito.png

05-food-page-tomato.png

06-shopping-desktop.png

07-pantry-desktop.png

08-household-nutrition-centre.png
```

Avoid spaces in filenames.

## Important

Do not modify application code.

Do not redesign pages.

Do not perform UI fixes.

Only generate the audit package.

The HTML gallery is intended to become the standard review package for future launch audits.
