# THA Picks Curation

> Add, edit and deactivate the preferred products THA puts in front of households.

## What it is

The capability, available to admins, to curate THA Picks — the preferred
real-world products THA recommends. An admin can add a pick, edit its details,
deactivate it so it stops being recommended, and reactivate it. A barcode lookup
against Open Food Facts helps populate a product's name, brand, quantity and
stores. This is where the recommended-product list households see is authored.
