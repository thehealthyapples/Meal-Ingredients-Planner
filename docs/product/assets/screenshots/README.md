# THA Screenshot Baseline — Manifest

_Captured by investigation PDA1 on 2026-07-11. Owner: Colin Clapson._
_Registry entry: [[shot-manifest]]. Governed by PKR §24 and Rule PKR10 (one owner per screenshot)._

This is the canonical screenshot baseline for The Healthy Apples. Each image is
**the** canonical picture of one surface (Rule PKR10), captured at a mobile
viewport (390 × 844 — THA is mobile-first per the UI Architecture) against a live
dev server and a real, seeded **demo household** (`POST /api/demo/start`). No image
is mocked, and no fixture data was invented.

## How it was captured

```
# The dev server must be running (npm run dev, port 5000).
LD_LIBRARY_PATH=<chromium-libs> npx tsx scripts/capture-product-screenshots.ts
```

`scripts/capture-product-screenshots.ts` is the single reproducer. It opens one
demo household, captures the household surfaces with that session, captures the
public surfaces with none, and writes `manifest.json` (the machine-readable record
of what was captured, with each surface's HTTP status).

**On the library path.** The environment ships chromium
(`chrome-headless-shell-1223`) but not the system shared libraries it links. All
of them are present in the Nix store; symlinking them — **excluding the glibc
core** — onto `LD_LIBRARY_PATH` lets chromium launch. The inherited claim that "no
browser binary can be installed in the current environment" was therefore false,
and this baseline is the refutation. See the PDA1 report for the full method.

## Deliberate gaps (recorded, not hidden)

- **Admin surfaces** (`/admin/*`, 13 pages) and **developer surfaces** are **not**
  captured. They require an admin session; the baseline's purpose is the household
  experience. This residual gap is what the finding `fnd-no-screenshot-baseline`
  now records — downgraded from "no baseline exists at all" to "the household
  baseline exists; the admin/developer baseline does not yet."
- **Modals, drawers and sheets** are not captured as separate images — they are
  surfaced within their host page. The dialog/drawer/sheet inventory is owned by
  [[dlg-inventory]], not by this baseline.

## The images
