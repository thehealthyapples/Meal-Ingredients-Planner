# Citrus, Berries and Stone Fruit — batch-004-citrus-berries-stone-fruit

This batch contains **30 individual canonical food YAML drafts** for The Healthy Apples.

Scope: Common citrus fruits, berries, currants and stone fruits found fresh, frozen or plain in UK supermarkets.

## Important controls

- One food per YAML file.
- Do not import `manifest.yaml`, `README.md` or the Claude prompt.
- Run the fixed importer in dry-run / validation mode first.
- Do not use `--force-upsert`.
- Alias-resolved identity matches should become merge/enrichment candidates, not duplicate foods.
- Unresolved nutrients, benefits, aliases or identity conflicts must be stopped for review.
