# Tea & Coffee plaster wall — wall continuity correction (edit)

## Canonical prompt

A photorealistic pantry corner: an oak shelf of ceramic tea/coffee canisters with hanging mugs and a cafetière on a stone worktop. Keep EVERYTHING else exactly the same as the base image — the same canisters, mugs, cafetière and grinder, the same oak timber, the same stone worktop, the same props, the same composition, the same objects in the same positions, the same camera, framing and warm lighting. Change ONLY the background wall to **smooth pale lime-plaster** matching the rest of the pantry (soft off-white/cream plaster, gently textured, warm daylight). It must read as another camera position inside the SAME handcrafted oak-and-plaster pantry. Photoreal, calm, warm.

## Negative constraints

No rough stone wall. No exposed brick. No different room. No tile. Do not move, add or remove any object, prop, shelf or furniture. Do not change the timber, the worktop, the camera, framing, proportions or lighting. No text, no logos.

## Candidate strategy
Single edit from the base plate via images/edits; reject if the wall is still stone/brick or if the composition changes.
