ACTIVE TAB COLOUR APPROACH

  The ModeSwitcher is rendered inside PageHeader which carries
  data-realm="basket". CSS custom properties defined in index.css
  under [data-realm="basket"] are therefore inherited by the tab buttons.

  Light mode values used:
    --realm-bg:   hsl(26, 20%, 91%)  — warm beige (same as banner background)
    --realm-text: hsl(26, 24%, 20%)  — warm dark brown (same as banner title)

  Dark mode values (auto, no extra code needed):
    --realm-bg:   hsl(26, 12%, 13%)  — dark warm brown
    --realm-text: hsl(26, 17%, 72%)  — warm mid-light

  The active tab now uses exactly the same hue family (26°, warm orange/sand)
  as the Shopping page banner, visually tying the selected stage to the header.
