NOTABLE BEHAVIOUR DELTA (visual only, no data impact)

  1. Shop qty display: was a large leading column (font-semibold text-[15px] before
     the name). Now inline with name (text-xs muted, after name). Same value shown,
     different weight/position. Change matches the unified spec: "quantity shown
     beside item name where available."

  2. Prep hint line: was shown in col 2 for all states (e.g., "Pantry item" amber
     alongside the PrepActionPanel's own "Common pantry item — check before buying").
     Now hint is suppressed in Prep mode — PrepActionPanel carries all context, so
     there is no duplicate text. For attention/multi-source items in Prep where
     PrepActionPanel returns null, the hint is also suppressed; the Prep group header
     ("Needs Attention") already signals these items.

SUGGESTION (out of scope — do not implement without separate approval)

  1. Shop qty weight: the Shop qty was previously styled as font-semibold text-[15px]
     (prominent leading anchor for in-store scanning). The unified style is text-xs
     muted (consistent with Review/Prep). If user research shows shoppers prefer the
     larger leading qty in-store, a shop-specific qty weight could be restored within
     the same col 2 without breaking the grid.

  2. Prep hint on null-panel items: items in Prep that have needsReview=true but are
     not pantry/uncertain (PrepActionPanel returns null) no longer show a "Needs
     attention" hint inline. If inline visibility is needed for these, the condition
     could be relaxed to: show hint when !shopMode AND (PrepActionPanel would return
     null). This requires a lightweight check of the same isPantryStocked/conf flags.

  3. Score min-width: col 4 is "auto" — if many rows have no score, col 4 shrinks to
     the chevron width only (16px). Adding a min-width like w-8 to col 4 would ensure
     the chevron always sits at a consistent x-position regardless of score presence.

  4. Analyse in Prep/Shop expanded: the expanded panel still shows a secondary Analyse
     link for Prep/Shop modes. As the primary Analyse button is now only in Review,
     consider whether a small Analyse icon-only button in col 3 of Prep/Shop rows
     (alongside the primary CTA) would reduce the need to expand just to analyse.

  5. Mobile col 3 wrapping: on very narrow screens (< 360px), col 3 with two buttons
     may push col 4 off screen. Adding overflow-hidden or a max-w constraint to the
     grid could prevent this if reported in testing.
