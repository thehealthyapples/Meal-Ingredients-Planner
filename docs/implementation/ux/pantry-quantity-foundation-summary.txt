API CHANGES
──────────────────────────────────────────────────────────────────────────────

POST /api/pantry — extended (backward compatible)
  New optional fields accepted:
    needQuantityValue: number (positive, finite) | null  — optional
    needUnit: string (max 32 chars) | null               — optional
  Existing creates without these fields still work unchanged.

PATCH /api/pantry/:id — new route
  Purpose: update quantity fields on an existing pantry item
  Auth: required
  Body:
    needQuantityValue: number (positive, finite) | null  — required
    needUnit: string (max 32 chars) | null               — required
  Responses:
    200 — updated item JSON
    400 — validation error
    404 — item not found / not owned by caller
    500 — server error
  Behaviour:
    Only updates needQuantityValue and needUnit.
    Passing null clears the field.
    Preserves all other item fields.
    Checks household ownership — cannot update other users' items.
