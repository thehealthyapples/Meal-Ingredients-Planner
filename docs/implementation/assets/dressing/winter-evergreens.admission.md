## 0. The wreath conflict, surfaced and resolved (Architecture Bootstrap · HOMEOWNER1)

The LH2 brief lists the winter object as an **"evergreen wreath."** A **wreath is classified by the canon as *celebration* dressing**, not seasonal: LIVINGHOME2 §5 and §8 name *"a simple **Christmas** wreath"* as **celebration-gated (Phase 5)**; §7.2 makes it lawful **only** for a household that has **declared** the occasion (LH1) **and explicitly permitted dressing for it**; §10.4 gates Phase 5 behind `LIVINGHOME1` Phases 1–3 (the traditions domain + the per-tradition dressing-permission mechanism). **None of that exists** — there is no traditions domain, no declaration, and no §7.2 permission — and §6 refuses *"any religious or cultural marker shown without the household's declaration."* A wreath shown to every household in winter would be exactly that.

Admitting a wreath now would therefore (a) contradict LIVINGHOME2's own classification, (b) breach §6/§7.2/ED9, and (c) be an **exception-by-instruction, which HOMEOWNER1 forbids** (*"the Home Owner exercises authority through the governing documents, never around them; a decision contradicting a governing rule is an amendment proposal, never an exception"*). Relabelling a wreath "seasonal" to dodge the gate is the §9.10 **forgery** the classification test exists to catch.

**Resolution (the lawful winter object):** the winter seasonal object is admitted as **winter evergreens** — a few evergreen sprigs gathered in a jug, *"deep-winter comfort"* (LIVINGHOME2 §5) — the green that endures midwinter, brought indoors, **carrying no occasion**. This honours the brief's *winter evergreen* intent by the only lawful reading. **The wreath itself is deferred to Phase 5**, to be admitted (if ever) through §7.2's declared-and-permitted gate once that mechanism is built — never before.
